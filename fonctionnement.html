🛡️ Presidio Browser Anonymizer

Masquez automatiquement vos données personnelles avant de les envoyer à ChatGPT, Claude, Gmail ou tout autre site.

🔒 100 % local : rien ne quitte votre ordinateur

✨ Le principe en un coup d’œil

Vous collez

Je m’appelle Jean Dupont, e-mail : jean@example.com, tél. : 06 12 34 56 78
➜

Le site reçoit

Je m’appelle [PERSONNE], e-mail : [EMAIL], tél. : [TELEPHONE]

⚙️ Comment ça marche ?

Vous collez

L’extension Chrome détecte le collage ou l’envoi de texte dans une page web.

Envoi au backend local

Le texte est transmis à localhost:6677, sur votre propre machine.

Analyse Presidio

Microsoft Presidio et spaCy repèrent noms, e-mails, téléphones, IBAN, numéros d’identité…

Anonymisation

Chaque donnée sensible est remplacée par une étiquette, par exemple [PERSONNE].

Texte sécurisé

Le texte anonymisé remplace l’original dans le champ de saisie.

🧩 Les composants

🌐 Extension Chrome

Intercepte le texte dans les pages, affiche la fenêtre d’options et le popup, et gère la langue (français par défaut, anglais disponible).

🐍 Backend Python (Flask)

Moteur local exposé sur le port 6677 : analyse le texte avec Presidio et renvoie la version anonymisée.

📊 Tableau de bord

Interface web pour tester l’anonymisation, ajuster les types de données détectées et consulter les statistiques.

📦 Installateurs

Scripts pour Windows, macOS et Linux qui installent Python, les dépendances et le modèle linguistique.

🔍 Ce qui est détecté

👤 Identité

Noms, prénoms, adresses, numéros d’identité (PESEL…), dates de naissance.

📞 Contact

E-mails, numéros de téléphone, URL, adresses IP.

💳 Finance

Cartes bancaires, IBAN, numéros de compte, identifiants fiscaux.

🚀 Démarrage rapide

1. Téléchargez le projet et lancez l’installateur (Windows : double-clic sur Uruchom-Windows.bat).

2. Dans Chrome, ouvrez chrome://extensions/, activez le mode développeur, puis « Charger l’extension non empaquetée » et choisissez le dossier chrome-extension.

3. Vérifiez que le backend répond :

curl http://localhost:6677/health

Collez ensuite un texte contenant des données personnelles dans ChatGPT : elles sont masquées. ✅

🔒 Confidentialité

Aucune donnée n’est envoyée sur Internet.
L’analyse se fait intégralement sur votre ordinateur. Internet n’est nécessaire que pour le téléchargement initial.
