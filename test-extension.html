🧪 Test Presidio Extension - Auto-Anonymization

Comment tester l’extension :

  1. Vérifiez que l’extension est activée (bouton vert dans la fenêtre contextuelle).
  2. Ouvrez les DevTools (F12), puis accédez à l’onglet Console.
  3. Copiez le texte de test ci-dessous (Ctrl+C).
  4. Collez-le dans le champ de texte ci-dessous (Ctrl+V).
  5. Vérifiez que les messages suivants apparaissent dans la console :
    [Presidio] Paste event detected - extension ENABLED
    [Presidio] Sending anonymization request...
    [Presidio] Received response: ...
  6. Le texte doit être automatiquement anonymisé avant d’être collé.

🔍 Débogage - Vérifier le script d’arrière-plan

Comment consulter les journaux du script d’arrière-plan :

  1. Ouvrez chrome://extensions/.
  2. Repérez « Presidio Browser Anonymizer ».
  3. Cliquez sur « Inspect views: service worker ».
  4. Les messages suivants doivent apparaître dans la console :
    [Presidio Background] Backend URL: http://localhost:6677
    [Presidio Background] Sending request to: ...
    [Presidio Background] Response status: 200
