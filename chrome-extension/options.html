⚙️ Configuration

MasqueIA v1.0.0
Adresse du serveur Presidio Anonymizer (par défaut : http://localhost:6677)

🚀 Assistant d’installation du backend

Choisissez votre système d’exploitation pour afficher les instructions détaillées.

💻 Installation pour Windows

1
Vérifier Python

Ouvrez l’invite de commandes et vérifiez que Python est installé :

python --version

Si Python n’est pas installé, téléchargez-le depuis python.org (cochez « Add Python to PATH » !)

2
Télécharger le projet
git clone https://github.com/jpsangare/presidio-local-anonymizer cd presidio-local-anonymizer

Vous pouvez aussi télécharger le ZIP depuis GitHub et le décompresser.

3
Lancer l’installateur
install-windows.bat

L’installateur crée automatiquement un environnement virtuel, installe les dépendances et démarre le backend.

4
Backend prêt !

Le backend démarrera sur : http://localhost:6677

Tableau de bord : http://localhost:6677/dashboard

📄 Voir install-windows.bat 📖 Documentation complète

🍎 Installation pour macOS

1
Vérifier Python

Ouvrez le Terminal et vérifiez que Python 3 est installé :

python3 --version

Si Python n’est pas installé, installez-le avec Homebrew : brew install python3

2
Télécharger le projet
git clone https://github.com/jpsangare/presidio-local-anonymizer cd presidio-local-anonymizer

Vous pouvez aussi télécharger le ZIP depuis GitHub et le décompresser.

3
Lancer l’installateur
chmod +x install-mac.sh ./install-mac.sh

L’installateur crée automatiquement un environnement virtuel, installe les dépendances et démarre le backend.

4
Backend prêt !

Le backend démarrera sur : http://localhost:6677

Tableau de bord : http://localhost:6677/dashboard
